Learn population genetics through simulation

GenDiversity is an educational Wright–Fisher model simulator for exploring genetic drift, allele frequency change, and inbreeding risk across generations.

About
This project is a conservation genetics learning application designed to help students and recruiters understand how stochastic population processes can affect long-term diversity.

Wright–Fisher Model

Discrete-generation population model

Simulates allele sampling across generations in a finite population.

Interactive Simulation

Parameter controls for exploration

Adjust population size, mutation, selection, and intervention settings in real time.

Real-Time Visualization

Dynamic chart output

Visualizes allele frequency and inbreeding coefficient trajectories generation by generation.

What does this application simulate? +
It simulates allele-frequency dynamics with a Wright–Fisher-style model, including mutation, selection, drift, and optional migration intervention.
Is this a production conservation analytics platform? +
No. This is a student portfolio project focused on learning and visualization. It is not presented as a deployed decision-support system.
Does it analyze real genomic datasets? +
No. Outputs come from mathematical assumptions and stochastic sampling in the simulator, not from real genome sequencing data.
What can users learn here? +
Users can explore how population size, mutation rate, selection pressure, and migration influence genetic drift and inbreeding trends over time.

Project Limitations

This is an educational simulation tool.

It does not analyze real genomic datasets.

Results are based on mathematical models and assumptions.

It is intended for learning and visualization purposes.
